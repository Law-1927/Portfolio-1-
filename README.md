# Lawrence Maullon — Portfolio

A lightweight, static portfolio starter built with semantic HTML, CSS, and vanilla JavaScript.

## Run locally

Open `index.html` in a browser, or serve this folder with any static file server. No build step or dependencies are required.

## Before publishing

- Replace the resume and contact placeholders with approved, working links.
- Confirm experience dates, titles, and descriptions.
- Get permission before publishing internal project details or screenshots.
- Add only public repositories and demos; review them for secrets first.
- Add approved images and evidence, and keep cybersecurity write-ups within platform rules.
- Check the site at mobile and desktop sizes and test navigation with a keyboard.
